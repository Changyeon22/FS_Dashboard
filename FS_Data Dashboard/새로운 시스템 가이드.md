# 🚀 새로운 시스템 가이드 (DB 기반)

## 📌 시스템 개요

### 변경 사항
기존의 이메일 기반 시스템에서 **DB 기반 자동 수집 시스템**으로 전환되었습니다.

**이전 시스템:**
```
이메일 수집 → GPT 파싱 → 로컬 엑셀 저장 → 대시보드 표시
```

**새로운 시스템:**
```
게임 백업 DB → 웹 DB 저장 → 대시보드 표시
       ↓
  매일 오전 9시 자동 실행
```

## 🛠️ 초기 설정

### 1. 필요 라이브러리 설치

```bash
pip install -r requirements.txt
```

### 2. 환경 변수 설정

`.env` 파일을 생성하고 다음 내용을 설정하세요:

```env
# 게임 백업 DB 설정 (SQL Server)
BACKUP_DB_SERVER=10.20.252.178
BACKUP_DB_PORT=1433
BACKUP_DB_USER=your_username
BACKUP_DB_PASSWORD=your_password
BACKUP_DB_DRIVER=ODBC Driver 17 for SQL Server

# 프로젝트별 DB 이름 (실제 DB 이름으로 변경)
BACKUP_DB_FS1_KOR=FS1_KOR_DB
BACKUP_DB_FS1_CHN=FS1_CHN_DB
BACKUP_DB_FS1_SEA=FS1_SEA_DB
BACKUP_DB_FS2_KOR=FS2_KOR_DB
BACKUP_DB_FS2_CHN=FS2_CHN_DB
BACKUP_DB_FS2_GSP=FS2_GSP_DB

# 웹 DB 설정 (로컬 SQL Server)
WEB_DB_SERVER=localhost
WEB_DB_NAME=FS_Dashboard
WEB_DB_PORT=1433
WEB_DB_USE_WINDOWS_AUTH=True
# Windows 인증을 사용하지 않는 경우:
# WEB_DB_USER=your_username
# WEB_DB_PASSWORD=your_password

# 데이터 수집 스케줄
COLLECTION_TIME=09:00
COLLECTION_TIMEZONE=Asia/Seoul
```

### 3. SQL Server 드라이버 확인

ODBC Driver 17 for SQL Server가 설치되어 있는지 확인하세요.

**설치 방법:**
1. [Microsoft ODBC Driver 17 for SQL Server](https://docs.microsoft.com/en-us/sql/connect/odbc/download-odbc-driver-for-sql-server) 다운로드
2. 설치 후 시스템 재시작

**설치 확인:**
```powershell
Get-OdbcDriver | Where-Object {$_.Name -like "*SQL Server*"}
```

### 4. 웹 DB 초기 설정

배치 파일을 실행하여 웹 DB를 생성하고 테이블을 설정하세요:

```bash
"6. 웹 DB 초기 설정.bat"
```

또는 직접 실행:
```bash
python setup_web_db.py
```

## ⏰ 자동 데이터 수집 설정

### Windows 작업 스케줄러 설정

매일 오전 9시에 자동으로 데이터를 수집하도록 설정합니다.

**방법 1: GUI로 설정**

1. **작업 스케줄러** 실행 (`taskschd.msc`)
2. **작업 만들기** 클릭
3. **일반 탭:**
   - 이름: `FS Dashboard 데이터 수집`
   - 설명: `매일 오전 9시 게임 DB에서 데이터 수집`
   - 사용자 로그온 여부에 관계없이 실행 체크
4. **트리거 탭:**
   - 새로 만들기 클릭
   - 매일, 오전 9:00 설정
5. **동작 탭:**
   - 새로 만들기 클릭
   - 프로그램/스크립트: `프로젝트경로\5. 데이터 수집 실행 (스케줄러).bat`
   - 시작 위치: 프로젝트 폴더 경로
6. **조건 탭:**
   - 컴퓨터의 전원이 AC인 경우에만 시작 체크 해제
7. **설정 탭:**
   - 작업이 실패한 경우 다시 시작 간격: 1분
   - 다시 시도 횟수: 3회

**방법 2: PowerShell로 설정**

```powershell
$action = New-ScheduledTaskAction -Execute "C:\Users\bae22\FS_Data Dashboard\5. 데이터 수집 실행 (스케줄러).bat" -WorkingDirectory "C:\Users\bae22\FS_Data Dashboard"
$trigger = New-ScheduledTaskTrigger -Daily -At 9am
$settings = New-ScheduledTaskSettingsSet -AllowStartIfOnBatteries -DontStopIfGoingOnBatteries
Register-ScheduledTask -TaskName "FS Dashboard 데이터 수집" -Action $action -Trigger $trigger -Settings $settings -Description "매일 오전 9시 게임 DB에서 데이터 수집"
```

### 로그 확인

수집 로그는 `logs/` 폴더에 저장됩니다:
```
logs/data_collection_20251016_090000.log
```

## 🔧 문제 해결

### 웹 DB 연결 실패

**증상:** `[ERROR] 웹 DB 연결 실패`

**해결 방법:**
1. SQL Server가 실행 중인지 확인
2. `.env` 파일의 `WEB_DB_SERVER`, `WEB_DB_NAME` 확인
3. Windows 인증 사용 시 `WEB_DB_USE_WINDOWS_AUTH=True` 설정
4. SQL Server 인증 사용 시 사용자명/비밀번호 확인

### 게임 백업 DB 연결 실패

**증상:** `[ERROR] 게임 백업 DB 연결 실패`

**해결 방법:**
1. 네트워크 연결 확인 (10.20.252.178 접근 가능한지)
2. 방화벽 설정 확인
3. `.env` 파일의 프로젝트/국가별 DB 이름 확인
4. 사용자 권한 확인

### ODBC 드라이버 오류

**증상:** `ODBC Driver 17 for SQL Server를 찾을 수 없습니다`

**해결 방법:**
1. ODBC Driver 17 설치
2. 설치 후 시스템 재시작
3. `.env`의 `BACKUP_DB_DRIVER` / `WEB_DB_DRIVER` 확인

### 데이터가 표시되지 않음

**해결 방법:**
1. 웹 DB에 데이터가 있는지 확인:
   ```bash
   python web_db_handler.py
   ```
2. 데이터 수집이 정상적으로 실행되었는지 로그 확인
3. 필요시 수동으로 데이터 수집 실행
